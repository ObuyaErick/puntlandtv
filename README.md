# Puntland TV Mobile App

The official mobile application for Puntland TV, built with Flutter. This app delivers a seamless digital media experience, offering 24/7 live television streaming, real-time news articles, Video on Demand (VOD), and background audio broadcasting.

## 📱 Features

- **Live TV:** Continuous HLS live streaming with picture-in-picture (PiP) support.
- **Latest News:** Rich-text news articles categorized by topic (Politics, Entertainment, Sports).
- **Video on Demand:** Browse and watch past shows and exclusive clips.
- **Background Audio:** Listen to Puntland Radio streams while navigating away from the app.
- **Breaking Alerts:** Real-time push notifications for urgent news updates.
- **Offline Reading:** Bookmark articles to a local SQLite database for offline access.
